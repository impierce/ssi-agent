# UniCore Documentation Source Files

Welcome to the source repository for the official documentation of **UniCore**, our self-sovereign digital identity agent.

## About

All the markdown (`.md`) files in this folder serve as:

1. **Source files** for the official UniCore documentation, hosted at: 👉 [UniCore Official Documentation (Beta)](https://beta.docs.impierce.com/unicore/)
2. **AI Context** for cloud agents and developers working on the codebase

These markdown files are used as input for generating the official documentation site. Changes to these files will reflect on the site after they are processed and deployed.
