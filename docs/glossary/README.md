# Glossary

This glossary defines key terms and concepts used throughout the UniCore SSI Agent codebase and documentation. It serves as a shared reference for both AI agents and human developers.

## Using This Glossary

- **For Developers**: When working with the codebase, refer to terms here to understand domain language and bounded context concepts.
- **For AI Agents**: This glossary provides essential context for understanding domain concepts, architectural decisions, and terminology.

## Term Categories

- **[Core Identity Concepts](./terms.md#core-identity-concepts)** - Fundamental SSI and identity-related terms
- **[OpenID4 Protocols](./terms.md#openid4-protocols)** - OpenID4VCI, OpenID4VP, and SIOP v2 protocol terms
- **[Architecture & Patterns](./terms.md#architecture--patterns)** - DDD, CQRS, bounded contexts, and design patterns
- **[Credential Lifecycle](./terms.md#credential-lifecycle)** - Terms related to credential creation, issuance, and verification

## Adding New Terms

When adding terms to the glossary:

1. Find the appropriate category in [terms.md](./terms.md)
2. Add the term in alphabetical order within that category
3. Provide a clear, concise definition
4. Link to related concepts where helpful
5. Reference relevant code locations if applicable
